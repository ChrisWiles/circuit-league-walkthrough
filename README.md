# Circuit League walkthrough

[Open the current walkthrough](https://chriswiles.github.io/circuit-league-walkthrough/).

One page follows the League player journey: introduction, setup, play settings, venues, partnerships, offers, scan, chat, scores, populated leaderboards, records and safety. All screenshots appear in order, with an optional enlarged viewer. There is no chapter-link navigation or historical-design tour. Retired tour URLs redirect to the current page.

The leaderboard uses text-only rows, with fixed partners on separate alphabetical lines. Provisional status remains on the detail record. Recent PD uses up to ten confirmed, fully played games and shows the actual count. Positive PD is green, negative PD is red, and zero is neutral. Player records explain the statistic; collapsed and expanded match history use only that match or series. The current native verification is iOS Dark mode at Default app text size.

All people, matches and safety examples are fictional local fixtures. [Capture provenance](current-captures.json) distinguishes refreshed screenshots from retained unchanged current screens. See [verification and limits](current-evidence.md) for exact checks and coverage.

GitHub Pages publishes this repository’s main branch. Gallery publication does not deploy the Circuit app or database. Preview locally with `python3 -m http.server 8093 --bind 127.0.0.1`.

Score review now allows 48 hours after reporting, with push on report, push and enabled results email at 24 hours, and final push six hours before confirmation. Disputing stops confirmation and starts the separate 24-hour agreement window.
