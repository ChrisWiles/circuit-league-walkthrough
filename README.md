# Circuit League walkthrough

[Open the current tour](https://chriswiles.github.io/circuit-league-walkthrough/).

One page follows the player journey through joining, settings, courts, partnerships, offers, scan, chat, scores, searchable leaderboards, records, weekly and season recaps, and safety. Its 93 views include 33 refreshed original iOS captures in Dark mode at Default app text size. Tap a screen to enlarge it. There is no historical-design navigation; retired tour URLs redirect here.

The current app source is local main commit `ce075ef6a512eb90598925f53f08bb3aa5a4d2f1`. The refreshed examples include one selectable pinned partnership, actual rating-update dates, season and per-match PD%, game-specific stopping context, dated conduct links, player-record Block preview, one-favorite controls, and actual Circuit League weekly and season stories with frozen PD and badge explanations. Search, score reminders and unchanged journeys remain in the tour with their original capture provenance.

All people, matches and safety records are fictional local fixtures. [Capture provenance](current-captures.json) identifies every original image and hash, including retained unchanged screens. [Verification and limits](current-evidence.md) distinguishes current device checks from source/test coverage and release dependencies.

GitHub Pages publishes this repository's main branch. Publishing the walkthrough does not deploy the app, backend or Circuit website. The Rules article remains a separate Circuit website release. Preview locally with `python3 -m http.server 8093 --bind 127.0.0.1`.
